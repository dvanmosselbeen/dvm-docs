## Introduction

This is a handy app for `Android` devices. Once installed through the `Google App Store`, it gives you a shell like you are on a `GNU / Linux` computer. You can also install `GNU / Linux` apps in the termux shell. If you have an `Android` tablet with a keyboard, this become your ideal device to manage your remote `GNU / Linux` machines.

## Installing termux

On the `Google App Store` look for the app `termux` and install it. Simple like that.

## Working with packages

````commandline
Search: pkg search <query>
Install: pkg install <package>
Upgrade: pkg upgrade <package>
````

For example:

````commandline
pkg install openssh
````
