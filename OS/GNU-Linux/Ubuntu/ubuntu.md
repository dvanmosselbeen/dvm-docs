## Introduction

``Ubuntu`` is based on ``Debian GNU Linux``.  There are a few differences, however. ``Ubuntu`` is also focused on servers but also heavily focused for beginner desktop users. The packages (apps) available in ``Ubuntu`` are also much more recent than in ``Debian GNU / Linux``. The ``Debian GNU / Linux`` distribution tends to have older, but much more stable packages. For daily user usage, ``Ubuntu`` is probably a better choice. There is also some long term security update support as well as (paid) support available.

Generally speaking, ``Ubuntu`` has a higher hardware requirements than ``Debian GNU / Linux``.

As ``Ubuntu`` is based on and a derivation of ``Debian GNU / Linux``, both share same spirit and the documentation of ``Ubuntu`` and ``Debian`` could be useful. There are some Ubuntu specific configuration.
